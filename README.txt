StyleSpill V11 — Interactive Fashion Store

New features:
- Smart search by product number, name, category, color, style
- Wishlist
- Recently viewed
- Style Match tool
- Complete the Look recommendations
- Product code copy
- Local click analytics in Admin
- Product add/edit/delete with custom number, style, badge, photo and Shopee URL
- Store profile/avatar
- Export/import catalog backup
- Mobile menu with Admin link

Important:
This version is a static/local CMS. Product changes are stored in the browser/device used to manage the store. For a true shared online CMS, connect a database/backend later.
