CapCut Creator:
Edit catalog.js pada bagian CAPCUT_CREATOR untuk mengisi:
- name
- handle
- followers
- templates
- profileUrl (link Share Profile CapCut)
- bioLines

Catatan:
- assets.directory sengaja menggunakan root (.) agar cocok dengan struktur repository saat ini.
- .assetsignore mencegah worker.js dan wrangler.jsonc ikut menjadi aset publik.
- Jika CapCut terpasang, link profil CapCut biasanya dapat diteruskan perangkat ke aplikasi.
